# GogmaArtianPlanner

GogmaArtianPlannerは、『MONSTER HUNTER WILDS』のアーティア武器・巨戟アーティアの厳選を
支援するWebツールです。

ゲーム内の抽選の状態（RNG状態）をもとに、作りたい目標武器までの作成ルートを探し、
複数の武器をまとめた生産計画を立て、実際のゲーム操作を1手ずつ案内する実行ナビまでを
ブラウザだけで行えます。

## すぐ使う

- **アプリを開く**: <https://nekono-lazy.github.io/GogmaPlanner/>
- **詳しい使い方**（スクリーンショット付き）:
  <https://nekono-lazy.github.io/GogmaPlanner/#/guide>

インストールやアカウント登録は不要です。PCとスマートフォンのどちらのブラウザでも、
主要な機能をすべて使えます。

## このツールでできること

- RNG状態を、分かっている値の手動入力、またはゲーム内の抽選結果の観測から特定する
- 所持している通常アーティア・巨戟アーティアを登録し、作成の起点として使う
- 作りたい完成武器の条件（目標武器）を登録する
- 現在の状態から、目標武器の理想品へ到達する作成ルートを検索する
- 理想品へ向かう途中で使える状態（妥協状態）を、必要に応じて途中で採用する
- 複数の目標武器をまとめて、実際に作成する順番（生産計画）を計算する
- 実行ナビで、ゲーム内の操作を1つずつ確認しながら作成を進める
- 入力したデータをブラウザに保存し、JSONのコピーやファイルでバックアップ・復元する

## 基本的な使い方

代表的な流れは次のとおりです。すでに持っている武器や、使いたい作成ルートによって
必要な準備は変わります。すべての人がこの順番どおりにすべての手順を行う必要はありません。

1. **RNG状態を準備する**

   「RNG状態設定」で、分かっている値を手動入力するか、ゲーム内の抽選結果を観測して
   特定します。すべての値を常に揃える必要はなく、使う作成ルートによって必要な値が
   異なります。

2. **目標武器を登録する**

   「目標武器」で、作りたい武器種・属性、理想の復元ボーナス、理想スキルを登録します。
   必要なら妥協条件も設定できます。候補検索は常に理想品へのルートを探し、妥協条件を
   設定すると、そのルートの途中で使える状態も扱えるようになります。

3. **候補を検索する**

   「候補検索」で目標武器を選び、現在のRNG状態や所持武器などをもとに、理想品へ到達する
   作成ルートを検索します。

4. **ビルドリストへ追加する**

   使いたい候補をビルドリストへ追加します。複数の目標武器の候補をまとめておけば、
   生産計画でまとめて作成順を計算できます。

5. **生産計画を作る**

   ビルドリストから生産計画を作成します。複数の武器で共有されるRNGの進み方を考慮して、
   実際に作成する順番が計算されます。

6. **実行ナビでゲーム内の操作を進める**

   生産計画の「作成開始」後は、実行ナビがゲーム内で行う操作を1つずつ表示します。
   結果を確認しながら進めてください。PC / PS5でゲームを操作しながら、スマートフォンで
   実行ナビを確認する使い方もできます。

何をすればよいか迷ったときは、ダッシュボードの「次の操作」を確認してください。

## 必要な場合だけ行う準備

次の2つは、すべての人に必須の手順ではありません。使いたい作成ルートに合わせて行ってください。

- **通常アーティアカウンター**

  新しく作る通常アーティアの復元ボーナスまで予測する作成ルートを使う場合は、その武器種の
  通常アーティアカウンターを確定します。必要な武器種だけ設定すれば十分で、未確定のままでも
  利用できる作成ルートがあります。

- **所持武器**

  すでに持っている通常アーティア・巨戟アーティアを作成の起点に使いたい場合に登録します。
  所持武器を登録しなくてもツールは使えます。

詳しい操作方法やスクリーンショットは、アプリ内の
[「使い方」](https://nekono-lazy.github.io/GogmaPlanner/#/guide)を参照してください。

## データ保存とバックアップ

- 入力したデータは、利用しているブラウザの中（IndexedDB）に保存されます
- ユーザーアカウント、サーバーへの保存、クラウド同期はありません
- 保存されたデータは端末・ブラウザごとに別々です
- 管理できるのは1キャラクター分のデータです

端末を移行するときや、別のキャラクターのデータに切り替えるときは、「設定」の
「データ管理」にあるエクスポート / インポートを使います。

- **エクスポート（バックアップ）**: JSONをクリップボードへコピーするか、JSONファイルとして保存します
- **インポート（復元）**: JSONを貼り付けるか、JSONファイルを読み込みます

インポートは全置換です。現在保存されているデータはすべてバックアップの内容に置き換わるため、
必要なデータがある場合は先にエクスポートしてください。

## ローカルで使う

Node.js（Viteの要件を満たすLTS版）を用意して実行します。

```sh
npm ci
npm run dev
npm run build
npm run preview
```

ビルド結果は `dist/` に出力されます。GitHub Pagesの公開パスは
`/GogmaPlanner/` です。配信時は `LICENSE`、`THIRD_PARTY_NOTICES.md`、
生成された `licenses.md` も同梱してください。
